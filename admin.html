One-time setup

You only need to do this once per browser. Your key is saved only on this computer and is used solely to publish updates to this website's content.

  1. Open github.com/settings/personal-access-tokens/new and sign in.
  2. Under "Repository access," choose Only select repositories and pick baaldan.
  3. Under "Permissions → Repository permissions," find Contents and set it to Read and write.
  4. Click Generate token at the bottom, then copy the code it shows you (starts with github_pat_).
  5. Paste it below and click Save.
